Design System Showcase · Direction D (Keepsake)

All Logging Forms · Design Mockups

High-fidelity design mockups for all eight logging forms based on the approved Keepsake design system (Ledger grid × Bloom palette, serif voice, stroke icons, hairline rules, and zero emoji). Every form enforces the core specification invariant: shared editable timestamp controls sit directly above Save (with Sleep displaying start and end times in that section).
