Toddler Routine Tracker · Visual Design Exploration v2 · October 2026

Three design directions

v2, regenerated after feedback that v1 sat too close to the prototypes (emoji icons, similar system fonts). These three directions share no emoji in the product UI — a single minimal stroke-icon set instead — and deliberately diverge in type system, geometry, and mood: a Swiss grid, an organic editorial, and a dark instrument panel. All keep the settled features: eight Entry kinds, Watch Cards with quick actions, timestamp-above-Save logging sheets, and consistent Food Status colors.

Direction A

Ledger

A Swiss typographic register — the app as a well-kept record book. Square corners only, hairline rules instead of cards, entries set in monospace tabular figures like columns in a ledger. One signal color (a print-maker's red) marks every actionable element; everything else is black on white. The most restrained and the most typography-driven of the three.

  • Type is the interfaceUppercase grotesk headlines + monospace data. Hierarchy through weight and rules, never decoration.
  • One color, spent carefullySignal red for actions and the Watch state only. Destructive flows inherit the same red — its restraint is what makes the Reaction moment loud.
  • Zero radiusSquare edges everywhere. Feels deliberate, printed, archival — the anti-candy direction.

Where it shines / watch-outs
Shines: scannability (tabular mono numbers align perfectly), timelessness, and the strongest possible Reaction moment — when the interface's single color is also the alarm. Watch-outs: dark mode needs a full rethink (true inverse reads harsh — use the warm Bone paper instead of pure white-on-black); all-caps mono meta text must stay short or it fatigues; may feel austere for caregivers expecting warmth.
Direction B

Bloom

A soft organic editorial — the app as a beautifully typeset parenting journal. A large serif with italic accents, a warm paper canvas, and tracker icons set as line glyphs inside pastel discs. Pills and circles are the only geometry; nothing is a box. The sleep card is a sage "garden" panel; the Watch Period shows a real progress ring. This is the warmth of v1's Golden Hour, rebuilt on a completely different skeleton.

  • Editorial voiceSerif headlines with italic emphasis ("Milo's Friday"), italic serif timestamps in lists. Reads like a kept journal.
  • Circle grammarOrbs, pills, rings. Rows are capsule-shaped, the tab bar is a floating dark pill, icons live in pastel discs.
  • Garden paletteSage, terracotta, oat, butter — soft naturals. Status colors stay semantic: sage = safe, butter = watching, clay = avoid.

Where it shines / watch-outs
Shines: emotional warmth without emoji or illustration; the Watch ring is the clearest progress signal of the three; serif italics give timestamps a human voice. Watch-outs: capsule rows cost vertical space on dense logging days; serif + pastel needs contrast auditing (AA on every pastel pairing); dark mode must darken the paper to deep umber, keeping discs muted.
Direction C

Monolith

A dark instrument panel — mission control for the night shift. Everything is monospace, uppercase, and phosphor-lime on near-black; screens are bordered modules with status LEDs and labeled headers. Data density is the highest of the three, and nothing pretends to be friendly — it pretends to be reliable. Dark-first; the light theme is a secondary "day mode."

  • Console honestyLabeled panels, visible states, tabular data. Every screen answers "what's the status" in under a second.
  • One phosphor accentLime = go/ok/action. Amber = watch. Red = reaction/delete. Nothing else is colored.
  • Monospace everywhereOne typeface, sized by rank. Commands read like terminal verbs: LOG, WAKE, MARK SAFE.

Where it shines / watch-outs
Shines: night use without any warm-tone compromise (true black, OLED-friendly), highest density, instant status reading, and a distinctive identity no baby app currently owns. Watch-outs: the cold console voice can feel wrong at emotional moments (first tastes, reactions) — copy must stay human ("ends Sunday morning", not "T-41H"); day mode is real work, not an inversion; small mono text needs careful contrast checking.
Shared asset

One icon set, three liveries

All emoji are removed from the product UI. A single minimal stroke-icon set (1.7px, round caps, 24px grid) covers the eight Entry kinds plus navigation; each direction recolors it via currentColor — line glyphs in Ledger, pastel-disc glyphs in Bloom, dim phosphor in Monolith. Emoji remain allowed in one place only: the child's own avatar/photo, which is user content, not chrome.

Side-by-side

Which direction when

A · Ledger

The archivist

Choose if the product should feel like a precise, trusted record — closest to a clinical tool, expressed through typography alone.
  • Perfect number alignment (tabular mono)
  • Most restrained = strongest alarm moments
  • Light-first; dark mode needs a paper rethink
  • Risk: austere for a mainstream parent audience
B · Bloom

The journal

Choose if warmth and keepsake value lead, without a single emoji — serif, pastel, and rings carry the emotion.
  • Warmest voice of the three
  • Watch ring = clearest progress signal
  • Capsule rows cost vertical density
  • Risk: pastel contrast must be AA-audited
C · Monolith

The night console

Choose if the app's promise is reliability at 3am — status at a glance, OLED-true black, zero sentimentality.
  • Best-in-class dark mode (native, not inverted)
  • Highest data density
  • Most distinctive identity
  • Risk: console voice must not go cold on users
Recommendation: as before, all three sit on the settled IA (Now / Timeline / Foods / Settings, Watch Cards above the fold, timestamp-above-Save sheets). If the brand should feel like a keepsake, Bloom is the strongest candidate now that it carries zero prototype DNA. If the brand should feel like a tool, Monolith's night panel is the most differentiated option — and its light "day mode" can borrow Ledger's typography wholesale.
Implementation handoff

PWA now, iOS later

Shared engineering notes that apply to whichever direction is picked.

Token handoff (CSS custom properties → Expo theme)
Layer PWA iOS (Expo)
Color --bg, --surface, --accent, --safe / --watching / --avoid per direction Same names in a theme.ts; dynamic providers for dark mode
Icons Inline SVG sprite (<use>), stroke = currentColor Same paths wrapped as a react-native-svg Icon component — one source of truth
Dark mode prefers-color-scheme + manual toggle persisted locally (Monolith inverts the default: dark first) Expo userInterfaceStyle + same persisted override
Safe areas env(safe-area-inset-*) on tab bar & sheets; viewport-fit=cover react-native-safe-area-context; sheets use native detents
Typography System serif/mono stacks per direction — zero webfont downloads keeps PWA install light Same stacks map to iOS system fonts (New York serif, SF Mono) — no font bundling
Haptics None (no reliable web API) expo-haptics: light impact on Save, warning on Reaction Save
Non-negotiables carried through all directions
1. Eight Entry kinds, each reachable in ≤2 taps from Now. 2. Sleep timer state visible from every tab. 3. Watch Cards surface contextual quick actions on Now (ADR-0002). 4. Timestamp controls sit directly before Save on every logging/edit form. 5. Delete is confirm-and-scrub — the confirm dialog is the only guard, so it must be visually heavier than every other action. 6. Reaction logging is reachable mid-incident from both Now and any Watch Card. 7. Food Status colors (safe/trying/untried/avoid) stay consistent across the Foods list, pickers, and Watch Cards. 8. No emoji in product chrome — only the shared stroke-icon set.
