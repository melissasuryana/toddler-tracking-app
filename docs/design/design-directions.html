Toddler Routine Tracker · Visual Design Exploration · October 2026

Three design directions

Three polished, mutually exclusive visual directions for the tracker, derived from the settled spec (eight Entry kinds, Watch Periods, confirm-and-scrub delete, Meal/Introduction split) rather than from the throwaway prototypes. Each is presented as a token set plus the four highest-stakes screens: Home (one-handed, half-asleep logging), an active Watch Card, a logging sheet, and a timeline/foods surface. All three are designed PWA-first with a clean path to a native iOS build.

Direction A

Golden Hour

A warm, editorial, lamp-lit interface built around the app's real usage context: one hand, dim room, 3am. Serif display type gives it the feel of a kept baby journal rather than a medical tool; dark mode is the primary designed surface, not an inversion. The sleep timer is the emotional center of Home — a glowing "night card" — and everything else recedes.

  • VoiceA kept journal, not a dashboard. Serif headlines, generous whitespace, no chrome that doesn't earn its place.
  • Dark-firstDesigned in the dark and lifted into light — warm ambers instead of pure blacks, so a 3am screen never glares.
  • One action per cardEvery Home card has exactly one primary verb (Sleep, Feed, Change, Log). No icon grids to aim at.

Where it shines / watch-outs
Shines: night feeds (the actual worst-case context), emotional resonance for a keepsake-feeling app, strong differentiation from clinical competitors. Watch-outs: serif display type needs discipline at small sizes; the FAB must not fight the bottom-sheet model — it only opens the full eight-kind picker, never duplicating card actions.
Direction B

Playdate

Soft, rounded, and upbeat — the "friendly co-parent." Each of the eight Entry kinds owns a color and a bubble icon, so caregivers build muscle memory by color alone (purple = sleep, pink = feed, blue = diaper) without reading a word. Home is a two-column tile grid tuned for thumbs; delight comes from progress bars, a "marked safe" moment, and chunky, forgiving touch targets.

  • Color is the interfaceEight tracker colors used consistently everywhere — tiles, timeline rows, charts, and food-status pills.
  • Chunky & forgivingMinimum 44pt targets, 20–24px radii, big type. Designed for a parent holding a toddler.
  • Reward the routineMicro-celebrations when a Watch Period clears; gentle, never gamified-pressure.

Where it shines / watch-outs
Shines: learnability (color = tracker), approachability for less tech-confident caregivers, App-Store-friendly personality. Watch-outs: eight hues must be tamed in dark mode (desaturate to pastel-on-dark, never full saturation); emoji chips risk feeling juvenile for the medical tracker — keep Medical/Growth in the calmer violet family; confirm-and-scrub delete keeps its serious tone and never inherits the playful voice.
Direction C

First Light

Crisp, quiet, iOS-native minimalism. It leans entirely on platform vocabulary — grouped lists, segmented controls, sheet detents, SF-style type — so it feels like it shipped with the phone. Color is rationed: system blue for actions, green for safe, orange for watching, red only for Reaction and Delete. This is the fastest path from PWA to a native-feeling iOS build and the most accessible direction by default.

  • Native before novelPlatform patterns (grouped lists, sheets, segmented controls) mean zero learning curve on iOS.
  • Color is semantic onlyBlue = action, green = safe, orange = watch, red = reaction/delete. Nothing decorative.
  • Data density, calmlyThe timeline and foods list carry more rows per screen — this is the power-user direction.

Where it shines / watch-outs
Shines: accessibility (Dynamic Type, contrast, VoiceOver map cleanly), density for heavy logging days, and the smoothest PWA→iOS migration since every pattern is already platform-native. Watch-outs: can read as cold for a keepsake product — warmth must come from copy ("Milo's week") and the child photo, not decoration; destructive red Save needs the confirm sheet to carry the full weight of the no-restore Delete model.
Side-by-side

Which direction when

A · Golden Hour

The keepsake

Choose if the product should feel like a warm baby journal and differentiate on emotion.
  • Best-in-class 3am experience (dark-first)
  • Strongest brand identity
  • Most custom component work
  • Risk: serif + warm palette can skew precious
B · Playdate

The friendly co-parent

Choose if learnability and delight matter most, and the audience is broad/new parents.
  • Color-coded trackers = zero-reading muscle memory
  • Most App-Store personality
  • Emoji-forward scales may not age well
  • Risk: playful voice vs. serious medical moments
C · First Light

The quiet tool

Choose if speed-to-native and accessibility outrank personality.
  • Fastest PWA→iOS path (platform patterns)
  • Best a11y and data density defaults
  • Lowest custom-build cost
  • Risk: generic; warmth must come from copy
Recommendation: all three share the same information architecture from the settled spec — bottom tab bar (Now / Timeline / Foods / Settings), Home cards with one verb each, Watch Cards pinned above the fold, and timestamp-above-Save logging sheets. The directions are interchangeable skins over that skeleton, so the decision can be made on brand alone. If undecided, start with C's structure (cheapest to build correctly) and layer A's dark-mode warmth as the first refinement pass.
Implementation handoff

PWA now, iOS later

Shared engineering notes that apply to whichever direction is picked.

Dark mode prefers-color-scheme media query + manual toggle persisted locally Expo userInterfaceStyle + same persisted override

Haptics None (no reliable web API) expo-haptics: light impact on Save, warning on Reaction Save

Non-negotiables carried through all directions
1. Eight Entry kinds, each reachable in ≤2 taps from Now. 2. Sleep timer state visible from every tab. 3. Watch Cards surface contextual quick actions on Now (ADR-0002). 4. Timestamp controls sit directly before Save on every logging/edit form. 5. Delete is confirm-and-scrub — the confirm dialog is the only guard, so it must be visually heavier than every other action. 6. Reaction logging is reachable mid-incident from both Now and any Watch Card. 7. Food Status colors (safe/trying/untried/avoid) stay consistent across the Foods list, pickers, and Watch Cards.
